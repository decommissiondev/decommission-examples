# Webhook lookup and conditional routing

This synthetic blueprint receives a customer field, makes a mocked HTTP lookup and selects active/inactive routing branches. worker.ts was generated by the current DECOMMISSION compiler without manual edits.

Run npm ci and npm test in this directory. The tests verify routing and outbound request mapping with mock responses, webhook authentication, disabled replay access, and the recorded report signature. They make no real API calls.

replay-cases.json is the Studio replay input. The signed replay-report.json was requested from production Studio using this public blueprint and these mocks. issuer-public-key.pem is the public key retrieved from Studio, not a private signing key. Verify the key independently at https://studio.decommission.dev/api/verification-key before relying on provenance; a key stored alongside a report is not an independent trust anchor.

The report proves agreement for the recorded mocked cases. Local tests exercise the checked-in Worker separately. No live Make run, CRM integration, latency comparison or production cutover is claimed.
