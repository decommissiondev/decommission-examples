## Frequently Asked Questions

### What does DECOMMISSION do?
DECOMMISSION compiles supported Make.com JSON scenario blueprints into standalone, customer-owned TypeScript Cloudflare Workers.

### Can I try an example without paying?
Yes. Explore, clone, and execute any compiled example in this repository locally via Wrangler without fees or accounts.

### Which scenarios qualify?
Workflows utilizing standard webhooks, HTTP requests, JSON mapping, and deterministic conditional routing. See the full [Compatibility Matrix](docs/compatibility.md).

### What do I receive?
A production-ready TypeScript Worker package complete with local unit tests, API mock fixtures, Wrangler configuration, and a signed replay verification report.

### What does it cost?
DECOMMISSION operates on transparent per-blueprint ownership pricing. Check our current pricing tiers on Studio.

### Where do I test my own blueprint?
Upload your Make scenario export to our free [Studio Compatibility Assessment](https://decommission.dev/studio) to verify eligibility before purchasing.
